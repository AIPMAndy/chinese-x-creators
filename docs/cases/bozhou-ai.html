02 / 这个人做什么

通过持续输出 AI 编程与 Agent 实战内容，连接商单、工具服务和课程。作者公开拆分工资、自媒体、中转服务与其他收入。

03 / 商业链路

专业内容建立信任 → 沉淀有工具需求的用户 → 商单、工具及课程成交。具体 X 归因尚不可量化。

04 / 最值得研究的 3 件事

  • 同一受众可能同时购买教程和工具，收入具有多元化特征。
  • B 端客户对工具业务的贡献值得重点研究，但不是所有创作者都能照搬。
  • 依赖上游平台或模型的工具服务，存在供应链和合规风险。

05 / 普通人怎么开始

  • 围绕一个持续出现的用户问题输出 10 条实测内容。
  • 提供一个真实可用的免费样例，观察下载、注册和咨询。
  • 把不同变现来源单独记账，避免把公司流水当作个人利润。

06 / 哪些结论不能直接照抄

  • 104 万元包含工资，不等于 X 创作者收入。
  • 收入为作者估算，缺少独立审计及成本明细。
  • 截至日期在 2026 年内，不能直接视为完整自然年收益。
