# 从 0 到第一位付费客户：一套可执行的 14 天实验

适合已经具有真实工作经验、产品能力或某个行业技能的人。目标是**验证一次真实的成交意愿**，不承诺收益。

| 天数 | 动作 | 可验证产物 |
|---|---|---|
| 1–2 | 明确一个细分受众与痛点；对比 10 条真实讨论 | 受众-问题表 |
| 3–4 | 写 2 篇实际经验帖，给出操作过程、失败点和结果 | 2 条原创帖子 |
| 5–6 | 做可领取的免费模板、公开仓库或演示页 | 1 个可访问链接 |
| 7–8 | 持续回答同领域真实问题，记录被问得最多的需求 | 需求记录表 |
| 9–10 | 发布一次完整实战复盘，附上时间、成本、真实结果 | 1 篇长文 |
| 11–12 | 用一对一沟通验证需求与预算；不进行骚扰式私信 | 至少 5 条高质量需求反馈 |
| 13–14 | 给真实需求设计最小收费服务或工具，并记录是否有付费 | 报价页 / 订单或拒绝理由 |

## 核心漏斗

公开内容 → 主页点击 → 免费资产使用 → 合格咨询 → 报价 → 付费 → 复购。

逐段记录事件数量与来源。没有数据的项目不写“转化率高”。优先优化最早发生的明显流失点。

## 复盘问题

1. 哪条内容真正解决问题？是否有能复现的结果？
2. 多少人实际查看了交付物？
3. 有多少人表达明确预算和截止时间？
4. 收入扣除工具、平台和交付成本后是多少？
5. 哪个动作可以删除、简化、加速或自动化？
